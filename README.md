# 晶核猎人

浏览器端俯视角像素 Roguelite 生存游戏原型。当前包含矿卫、大剑、晶核经验、三选一升级、精英道具掉落、双主动槽与十二分钟 Boss 战，并采用可扩展的分层架构。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建：

```powershell
npm.cmd run build
```

## 操作

- `WASD`：八方向移动
- 鼠标：控制大剑自动挥砍方向
- `Space`：朝移动方向翻滚；静止时朝鼠标方向翻滚
- `Q` / `E`：手动释放两个主动槽中的道具
- `F`：靠近稀有晶脉后按住开采
- `1`、`2`、`3` 或鼠标点击：选择升级奖励
- `R`：死亡或结束后重新开始

## 当前可玩内容

- 矿卫初始拥有 120 生命、1 点护甲和荒铁大剑。
- 大剑按照冷却自动攻击，保留三段连击、击退、闪白、粒子和屏幕震动。
- 晶壳虫持续从房间边缘出现，敌群数量随十二分钟计时逐渐提高。
- 中段开始混入保持距离并发射晶刺的远程晶壳；后段加入带预警的蓄力冲锋怪。
- 2:30、5:00、7:30、10:00 出现精英；精英概率掉落实体道具。
- 主动道具槽满后触碰新主动道具会暂停战斗，可替换任一槽位或放弃新道具。
- 3:00、6:30、9:30 生成稀有晶脉；静止按住 F 2.5 秒完成开采，移动或受伤会中断，成功后暂停并进行道具三选一。
- 12:00 出现最终 Boss，Boss 战期间继续刷怪，击败 Boss 才能胜利。
- 晶巢领主拥有三段生命阶段：环形晶刺、瞄准散射和低血量高速冲锋逐步叠加，并显示独立 Boss 血条。
- 击败 Boss 后开启局外胜利宝箱，从三个尚未解锁的道具中选择一个永久解锁；下一局开始进入精英掉落池。
- 击败敌人掉落晶核经验，晶核会减速并在拾取范围内吸附玩家。
- 升级时暂停战斗，从三项随机奖励中选择一项。
- 开局先从矿卫、晶猎、探脉师中选择角色，再从荒铁大剑、磁轨晶弩、环轨钻头和裂变法杖中四选一；LV3 获得第二把武器。
- 三名角色拥有独立初始数值与天赋：矿卫低生命减伤、晶猎闪避后强化武器、探脉师每收集八枚晶核恢复生命。
- 普通升级只提高角色属性；LV6 起从两把武器当前可用的路线技能合并池中随机三选一。
- 每把武器拥有两条三技能路线；选中首个技能后锁定路线，完成三技能和材料后进化，再开放另一条路线。
- 路线技能不足三项时，以可重复的威力、频率和规模精炼补足；等待进化材料时仍暂存高级升级。
- 生命归零会结束本局并显示等级、命中数和生存时间。

更多角色、武器、道具和正式地图属于后续阶段。

## 工程结构

```text
src/
├─ application/  单局编排与领域效果适配
├─ content/      角色、升级等声明式内容
├─ core/         类型化事件等基础设施
├─ domain/       不依赖 Phaser 的规则、状态与快照
├─ combat/       伤害类型、武器接口和大剑表现
├─ entities/     Phaser 玩家与敌人适配
├─ director/     计时、敌群上限和生成节奏
├─ systems/      晶核掉落与吸附
├─ ui/           HUD、经验条、升级卡片和结算
├─ scenes/       Phaser 装配入口
└─ main.ts       Phaser 启动配置
```

`GameScene` 只负责创建并逐帧驱动 `RunSession`。升级内容只声明条件和效果，由应用层适配到 Phaser 对象。完整约束和扩展顺序见 [ARCHITECTURE.md](./ARCHITECTURE.md)。
