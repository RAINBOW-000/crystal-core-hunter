# 晶核猎人

浏览器端俯视角像素 Roguelite 生存游戏。当前版本包含两关完整流程、三名猎人、三把主武器、三把副武器、局内升级、永久解锁、关卡存档和差异化 Boss 战。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建：

```powershell
npm.cmd run build
```

需要复现一局时，可在地址后加入固定种子，例如 `http://127.0.0.1:5173/?seed=debug-001`。开发环境可用 `?stage=2` 从新游戏直接测试第二关。同一种子和相同操作会得到一致的刷怪、升级、掉落与晶脉奖励。

道具来源、暂停规则和替换流程见 [ITEM_DROP_FLOW.md](./ITEM_DROP_FLOW.md)。

怪物晶核、经验和移动开采规则见 [CORE_AND_MINING_RULES.md](./CORE_AND_MINING_RULES.md)。

## 操作

- `WASD`：八方向移动
- 鼠标：控制大剑自动挥砍方向
- `Space`：朝移动方向翻滚；静止时朝鼠标方向翻滚
- `Q` / `E`：手动释放两个主动槽中的道具
- `F`：靠近稀有晶脉后按住开采
- `V`：循环切换低、中、高三档战斗特效；关键攻击预警不会被关闭
- `Esc`：暂停战斗
- 冰封时按画面给出的 `A` / `B` / `C` / `D` 顺序挣脱
- `1`、`2`、`3` 或鼠标点击：选择升级奖励
- `R`：重新开始当前关

## 当前可玩内容

- 矿卫初始拥有 120 生命、1 点护甲和荒铁大剑。
- 大剑按照冷却自动攻击，保留三段连击、击退、闪白、粒子和屏幕震动。
- 第一关“晶核荒原”持续 7 分钟；第二关“极寒矿脉”持续 9 分钟。
- 中段开始混入保持距离并发射晶刺的远程晶壳；后段加入带预警的蓄力冲锋怪。
- 第一关每 90 秒出现精英，第二关每 2 分钟出现重新设计的冰脊猎手。
- 主动道具槽满后触碰新主动道具会暂停战斗，可替换任一槽位或放弃新道具。
- HUD 会显示 Q/E 主动道具的实时冷却与全部被动道具等级；道具奖励卡会预览获得或升级后的具体效果。
- 每关生成两处稀有晶脉；进入有效范围后按住 F 2.5 秒完成开采，成功后暂停并进行道具三选一。
- 第二关加入霜痕兽、冰脉唤刺者、冰面、预警落冰、寒冷叠层与冰封挣脱，并提供四件第二关专属道具。
- 第一关 Boss 在 7:00 出现，第二关 Boss 在 9:00 出现；Boss 战期间继续刷怪，击败 Boss 才能胜利。
- 晶巢领主拥有三段生命阶段：环形晶刺、瞄准散射和低血量高速冲锋逐步叠加，并显示独立 Boss 血条。
- 击败 Boss 后开启局外胜利宝箱，从三个尚未解锁的道具中选择一个永久解锁；下一局开始进入精英掉落池。
- 主菜单提供开始、继续、晶核档案和设置；关闭页面会保存当前关卡与种子，再次进入时从该关开头重开。死亡会把关卡进度重置到第一关。
- 击败敌人掉落晶核经验，晶核会减速并在拾取范围内吸附玩家。
- 升级时暂停战斗，从三项随机奖励中选择一项。
- 开局选择角色后直接进入矿区：矿卫绑定荒铁大剑、晶猎绑定晶核弩、探脉师绑定裂变法杖；主武器与角色均从 LV0 开始。LV3 从环轨钻头、地脉震荡器、折光卫星中选择一把自动攻击的副武器。
- LV6 起每 3 级进入主副武器共享的里程碑升级池；主武器保留双路线，副武器各有三段单路线与专属进化材料。
- 三名角色拥有独立初始数值与天赋：矿卫低生命减伤、晶猎闪避后强化武器、探脉师每收集八枚晶核恢复生命。
- 普通升级只提高角色属性；LV6 起从两把武器当前可用的路线技能合并池中随机三选一。
- 每把主武器拥有两条三技能路线；首个技能锁定当前路线，完成三技能和材料后进化，再开放另一条路线。副武器各有一条三技能路线和一次终极进化。
- 路线技能不足三项时，以可重复的威力、频率和规模精炼补足；等待进化材料时仍暂存高级升级。
- 生命归零会结束本局并显示等级、命中数和生存时间。

更多角色、武器、道具和正式地图属于后续阶段。

## 工程结构

```text
src/
├─ application/  单局编排与领域效果适配
├─ content/      角色、武器、道具、敌人与生成时间轴等声明式内容
├─ core/         类型化事件等基础设施
├─ domain/       不依赖 Phaser 的规则、状态与快照
├─ combat/       伤害类型、武器接口和大剑表现
├─ entities/     Phaser 玩家与敌人适配
├─ director/     计时、敌群上限和生成节奏
├─ systems/      晶核掉落与吸附
├─ ui/           HUD、经验条、升级卡片和结算
├─ scenes/       Phaser 装配入口
└─ main.ts       Phaser 启动配置
```

`GameScene` 只负责创建并逐帧驱动 `RunSession`。升级内容只声明条件和效果，由应用层适配到 Phaser 对象。完整约束和扩展顺序见 [ARCHITECTURE.md](./ARCHITECTURE.md)。
